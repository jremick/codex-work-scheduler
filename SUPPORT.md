# Support

Codex Work Scheduler is experimental public-alpha software. It is intended for technical operators who can inspect JSON output, local SQLite state, and Codex task status.

## Where to ask

- Use GitHub Issues for reproducible defects, documentation errors, and focused enhancement proposals.
- Use the private route in [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Before opening an issue, run the documented verification commands and search existing issues. Include the affected commit, macOS and Python versions, Codex CLI version, the command name, the redacted error code, and a minimal reproduction.

Do not post account identity, exact quota usage, paid-credit details, credentials, private prompts, task output, scheduler databases, approval files, or machine-specific paths. Do not upload raw logs. Reduce evidence to synthetic inputs and redacted error codes.

## Support boundary

There is no guaranteed response time, uptime, compatibility window, migration support, or recovery service during alpha. The maintainer may close reports that cannot be reproduced without private account data or unsupported local modifications.

Questions about Codex accounts, billing, authentication, or service availability belong in the relevant OpenAI support channel, not this repository.
