# License decision

Status: **approved and implemented**

Decision date: **2026-08-30**

The repository uses the **Apache License 2.0** for its code, schemas, examples, and documentation. The full, unmodified license text is in [`LICENSE`](../LICENSE).

## Rationale

- It permits private and commercial use, modification, and redistribution.
- It includes an explicit patent grant and patent-termination terms.
- One repository-wide license avoids a separate documentation-license boundary.
- The project has no vendored source, third-party runtime dependencies, datasets, fonts, media, or copied assets that currently require a separate notice.

The license's Appendix contains an example notice with placeholder fields as part of the standard text. This repository does not add or invent a separate copyright notice. A `NOTICE` file is not required by the current dependency and attribution review.

Unless a contributor explicitly states otherwise, contributions submitted for inclusion are accepted under Apache-2.0 without additional terms or a separate contributor license agreement. This decision does not authorize a visibility change, tag, release, package publication, or announcement.

This record is not legal advice.
